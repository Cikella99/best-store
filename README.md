# Best Store

E-commerce per scarpe custom.

## Struttura

- `index.html` — home
- `catalogo.html` — lista prodotti
- `prodotto.html` — scheda prodotto
- `carrello.html` — carrello
- `admin/` — pannello gestione prodotti/ordini
- `css/` — stili
- `js/` — script

## Stack

HTML/CSS/JS puro, nessun build tool richiesto. Pagamenti via Stripe, spedizioni via Shippo (da collegare in una fase successiva).
